# Skill: build a page

1. Find the page's goal and required content in `developer/site-map.md`.
2. Identify the buyer it serves in `developer/project-analysis.md`.
3. Build as a static server component. Add a client component only for real interactivity.
4. Use tokens from `developer/design-system.md`, and check text contrast.
5. Read contact and company details from `content/company.ts`.
6. Include an enquiry route within one click.
7. Add metadata, JSON-LD where relevant, and breadcrumbs on nested pages.
8. Use `TODO(client)` for missing facts, and log them in `client/open-questions.md`.
9. Run `skills/review-claims.md` on the copy.
10. Check at 360px and desktop widths, with keyboard only, and with reduced motion.
