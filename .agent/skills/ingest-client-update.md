# Skill: ingest new client information

Use when the client sends notes, files, answers or changes.

1. Save new notes verbatim as a new dated file in `client/`, such as `client/2026-11-20-update.md`. Do not overwrite earlier notes.
2. Put new brand or document files in `assets/`.
3. Move confirmed facts into `client/facts.md` with the date.
4. Delete answered questions from `client/open-questions.md`, and add any new ones.
5. Note conflicts with earlier material. Prefer the newest explicit statement, and ask if the conflict is material.
6. Update what the answer affects: `decisions.md`, `developer/`, `content/`.
7. If a `Proposed` decision is now settled, mark it `Accepted` with the date.
8. Summarise what changed and what is still blocking.
