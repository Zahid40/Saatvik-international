# Skill: add or change a product

Use when a product, grade, flavour or pack size is added or changed.

1. Confirm the information comes from the client. If not, stop and add a question to `client/open-questions.md`.
2. Add or edit the file in `content/products/`, following the `Product` type in `developer/site-map.md`.
3. Set `status: "draft"` if anything is unconfirmed, and `"confirmed"` only when complete.
4. Leave `moq` and `packaging` undefined if unknown, so the page shows "on request".
5. Write a unique SEO title and description. Add useful alt text to images.
6. Run `skills/review-claims.md` on all new text.
7. Update the catalogue table in `knowledge/products.md`.
8. Check the page, the category grid, the sitemap entry and the enquiry option labels.
